Join a peerdash canvas.

1. Call the `join` tool with this share link: $ARGUMENTS
   If there is no link, ask the user to copy it from the **Share** panel in
   their browser.
2. Tell the user in one or two lines what is on the canvas, from the outline
   that `join` returns.
3. Follow the `peerdash` skill for all later changes.
